# BallCollect 仕様

球をWASDで動かし、床の上のアイテム5個を集めるゲーム。入力はInput Systemで統一する。

## 完成条件

| ID | 内容 |
|---|---|
| B1 初期状態 | 床・球・カメラ・アイテム5個。回収数 0/5、CLEARは非表示 |
| B2 移動 | WASDで移動。W=+Z, S=-Z, D=+X, A=-X。カメラは固定視点 |
| B3 回収 | 触れたアイテムが消え、回収数が1増える。同じアイテムで二重加算しない |
| B4 クリア | 5個すべて回収したときだけCLEAR。途中では表示しない |
| B5 落下 | 位置・速度・回収数・アイテム・UIを初期化(位置だけ戻さない) |
| B6 Rで再開 | 途中でもクリア後でも同じ初期状態へ |

## 配置

- 床 20x20、球 (0, 0.5, -7)、アイテムは X=0 で Z = -4, -1, 2, 5, 8
- カメラは固定(球・アイテム列が見える斜め上)

## 範囲外

敵、外部アセット、効果音、複数ステージ、ランキング、オンライン、動画収録、ビルド
