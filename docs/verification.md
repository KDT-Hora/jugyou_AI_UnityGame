## ルール変更: 玉が穴に入ることでアイテム獲得

| 出来事 | 結果 |
|---|---|
| メダルに触れる | メダルが消え、玉が盤の上へ発射されるだけ(カウントは増えない) |
| 玉が「得点の穴」(中央・GET!) | アイテム獲得(+1)。5回でCLEAR |
| 玉が「ボーナスの穴」(左右・MEDAL!) | フィールドにメダルが8枚出現(`GameManager.bonusMedals`) |
| 玉がどの穴にも入らない(アウト口) | フィールドにメダルが1枚出現(`missMedals`) |
| クリア後・時間切れ後 | 玉が穴に入っても何も起きない |

実装: `GameManager.Collect`(拾う)と `ReportBall(BallResult)`(玉の結果)に分離。追加メダルは `MedalField`(複製元をインスタンス化、他のメダル・プレイヤーから離れた位置に出す)。初期メダルは5枚のままで、**詰みはない**(得点1回につきメダル1枚を消費するが、ボーナス/はずれで必ず補充されるため、5回得点するまでメダルが尽きない。EditModeで300シードのランダム検証)。

盤の調整(実測、玉100〜120個で集計。玉を1つずつ流して他の玉と干渉しない条件):
- 初期: 得点12% / ボーナス13% / はずれ74% → クリア困難。
- 途中で案内板の傾きの符号が逆(玉を外側へ導いていた)ことに気づき修正。
- 最終: **得点56% / ボーナス22% / はずれ23%**。
- 補足: 計測中に玉が雪だるま式に増えて(ボーナスのメダルを拾い続ける)結果が歪んだため、新メダルが出ない状態で測り直した。

ボット実験(一時的なテスト。コミットしていない): 最寄りのメダルまで移動時間(距離÷速度)だけ待って拾うボットが30秒でクリアできるか。5回中5回クリア、残り時間10〜23秒。ボットは操作が理想的なので、人間はもう少し難しい。キー操作版のボットは、床から落ちる・入力が効かなくなる等で実験として不適切だったため破棄した(ゲームの不具合ではなく実験側の問題)。

テスト: EditMode 23/23、PlayMode 18/18 合格。主な追加: 拾ってもカウントされない / 得点・ボーナス・はずれの各結果 / 穴に入った玉がアウト口でもはずれ扱いにならない / クリア後は無視 / リセットで追加メダルも消える / 詰みがない(300シード)。
画像: `evidence/rule_1_initial.png` `rule_2_launch.png` `rule_3_after.png`。Play中のコンソールは警告・エラー0。
注意: このルール変更とパチンコ台は、サブエージェントによるレビュー(3ラウンド)の後に作った部分で、未レビュー。

## スロット演出の撤去とパチンコ台の追加

- 撤去: 3リール、JACKPOT 777 看板、カウントの回転表示(`Juice` から関連コードとテスト用フィールド `rollDigitOverride` を削除)。コイン、電飾、サンバースト、フラッシュ等は残した。
- 追加: ステージ奥(z=11.5)に縦型のパチンコ台 `PachinkoBoard`。ピン約70本、回る風車2基(ピンク)、下に3つの穴(ランプ付き)とアウト口、縁の電飾。
- 動作: コインを拾うとコインの位置から玉が放物線で盤の上へ発射され(金色の軌跡)、そこから物理演算でピンの間を落ちる。穴に入るとランプが点滅・火花・画面フラッシュ/揺れ。アウト口で玉は消える。Rで全玉を消去。
- 隔離: 盤は専用レイヤー8で、ステージ(Default)とは衝突しない(プレイヤーが落ちても盤に引っかからない)。ゲームロジックは変更なし(`GameManager` のイベントを聞くだけ)。
- テスト: EditMode 12/12、PlayMode 14/14 合格。新規4件: 回収で玉が発射され最後にアウト口へ落ちる / Rで玉が全消去(飛行中も) / 盤がステージ物理に干渉しない / 穴の真上に落とした玉で穴イベントが出る。
- 途中で見つかった不具合: 穴の脇のくぎの間に玉が挟まって止まる(10球中1球)。穴の上のくぎを間引いて漏斗状にし、さらに静止した玉を揺らす保険を追加。修正後は15球×2回で全球が22秒以内に抜けた。
- 画像: `evidence/pachi_1_initial.png` `pachi_2_launch.png` `pachi_3_falling.png`(クリア時のフラッシュで白っぽい) `pachi_4_clear.png`。Play中のコンソールは警告・エラー0。
- 注意: 前回のレビュー(3ラウンド)は撤去前の構成に対するもの。パチンコ台の追加分は未レビュー。ユーザーの指示が「穴に」で途切れていたため、穴に入った時の挙動は「ランプ点滅・火花・フラッシュ」を仮に実装(要確認)。

## 不具合と対応

- 擬似入力(`simulate_key`)は押下状態だけを書き込み、`wasPressedThisFrame` が立たなかった。Rは `isPressed` の立ち上がり検出に変更。
- CLEARテキストが枠高さ不足で非表示だった。枠を拡大しOverflowに設定して解消。
